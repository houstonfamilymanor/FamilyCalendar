Notes

⚙ Settings

Everything here is saved in your family Google Sheet, not in the app's code.

Event tags

Label events (Lunch menu, Sports, Birthdays…) and turn each label on or off with the chips above the calendar. Tick Hide until turned on for detail you only want now and then, like what's for lunch: those events stay off the calendar until someone turns the tag on (each phone remembers its own choice). Deleting a tag takes it off events; the events stay.

Kids' schools

One row per kid. Paste their school's website link (the Dining page works best): the app reads that school's lunch menu and its own events calendar, nothing from other schools. Optionally paste the district's letter-day calendar link (from its "subscribe to calendars" page) and what each letter means, like A: Gym, B: Art, C: Music. Each kid gets Lunch · name and School · name chips above the calendar, off until you turn them on. Shown only in this app, never on Google Calendar.

Sender categories

If the sender's address or name contains the text, the email goes to that category and skips event suggestions. Tick Balance alert for lunch-account emails to get the child and dollar balance as an alert card with “Took care of it”. Everything else stays regular school mail.

Teachers

Who's who, so emails get tagged by kid. One per line: Name - Kid. Use the name as it appears on the email (e.g. Jane Smith - Sam) or the portal's style (J Doe - Mia). Matching uses the last name and, if you give one, the first initial.
